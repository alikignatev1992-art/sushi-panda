# Суши Панда — сайт доставки суши (Стерлитамак)

Интернет-магазин доставки суши и роллов «Суши Панда»: каталог с реальным
меню, карточки товаров, корзина с оформлением заказа, регистрация и личный
кабинет.

**Адрес:** Стерлитамак, Артёма 151 (здание Basconi) ·
**Телефон:** +7 965 641-67-57 · Ежедневно 11:00–0:00

## Стек

- [Next.js 16](https://nextjs.org) (App Router, Turbopack)
- [Tailwind CSS 4](https://tailwindcss.com)
- [shadcn/ui](https://ui.shadcn.com) на Base UI (Sheet, Tabs, Carousel,
  Field-формы, sonner-тосты и др.)
- Шрифт [Onest](https://fonts.google.com/specimen/Onest) через `next/font`
- TypeScript

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
```

Продакшен-сборка: `npm run build && npm start`.
Проверка типов: `npm run typecheck`.

## Что внутри

| Маршрут | Описание |
|---|---|
| `/` | Главная: промо-карусель (автопрокрутка), каталог 66 позиций с фильтрами по категориям, доставка и оплата, отзывы, контакты |
| `/product/[slug]` | Карточка товара: фото, цена, добавление в корзину, похожие позиции |
| `/account` | Регистрация / вход и личный кабинет: профиль, адрес доставки, история заказов |

- **Корзина** — выезжающая панель (Sheet): состав, степперы, форма заказа
  с валидацией (мин. заказ 700 ₽), способ получения и оплаты, кнопка
  «Заказать в WhatsApp» с автособранным текстом заказа.
- **Каталог** (`lib/catalog.ts`) — реальное меню и цены; фото блюд в
  `public/photos/`.
- **Дизайн-токены бренда** замаплены на переменные shadcn в
  `app/globals.css` (белый фон, оранжевый `#F1801F`, чёрный `#1B1B1B`,
  радиусы от 12px, тихая типографика).

## Ограничения (демо-режим)

Бэкенда пока нет: аккаунты, адрес и история заказов хранятся в
localStorage браузера; «Оформить заказ» показывает подтверждение, боевой
канал приёма заказов — кнопка WhatsApp. Следующий этап — API заказов и
авторизация по SMS.

## Структура

```
app/                 # маршруты (главная, product/[slug], account)
components/site/     # шапка, футер, каталог, карточка, корзина, промо
components/ui/       # компоненты shadcn/ui
lib/                 # каталог, корзина (context), auth (context)
public/photos/       # фотографии блюд
```
