# REPORT: приложение «Суши Панда» (Next.js + shadcn) — 2026-07-22

Папка: `04-build/sushi-panda-app/` (скопирована из заготовки `next-app`:
Next 16 + Tailwind 4 + shadcn, Base UI). Dev-сервер: конфиг `sushi-panda-app`
в `.claude/launch.json`, http://localhost:3000.

Решение о стеке: по маршрутизации среды личный кабинет + карточки товаров =
приложение → Next.js + shadcn. HTML-версия (`04-build/sushi-panda/index.html`)
остаётся как лендинг-прототип.

## Что собрано

- **Тема бренда** — токены `02-design-system/sushi-panda/tokens.css`
  замаплены в `app/globals.css` (:root; .dark технически = светлой,
  тема принудительно `forcedTheme="light"` — White-Stage). Шрифт Onest
  (cyrillic) через `next/font`; заголовки вес 500 (Quiet-Type);
  primary `#F1801F` c белым текстом (White-On-Orange, AA-исключение
  пользователя задокументировано в DESIGN.md); focus-ring `#E86A10`.
- **Каталог: 66 реальных позиций из VK** (`lib/catalog.ts`,
  автогенерация из `01-research/sushi-panda-vk/vk-community-data.md`) с
  реальными фото (`public/photos/*.jpg`, транслит-слаги). 4 сета с фото,
  но снятые с продажи в VK (Ёпсель-мопсель, А сейчас хочу я в пляс,
  Панданутые, Чёрная жемчужина) — не включены. Подарочные позиции
  («бесплатно») исключены. Составы — только подтверждённые; у остальных
  в карточке честная заглушка «состав уточняйте по телефону».
- **Главная** (`app/page.tsx`): 3 промо-баннера (Сет под солнцем
  1399/2223, доставка от 900 ₽, подарки от 1700/2600/3000 — факты VK),
  каталог с фильтрами-чипами (ToggleGroup) по 5 категориям, «Доставка и
  оплата», 4 реальных отзыва из VK (Card+Avatar), контакты, футер.
- **Карточка товара** `/product/[slug]` (66 статических страниц,
  generateStaticParams + metadata): крупное фото, бейдж категории, цена,
  «В корзину» → степпер + «Оформить», кнопка «На главную», блок
  «похожие из категории». Карточки в каталоге кликабельны целиком
  (Link-оверлей), кнопка корзины работает поверх.
- **Корзина** (`lib/cart.tsx` + `components/site/cart-sheet.tsx`):
  контекст + localStorage; Sheet со списком (фото, степперы), итогом и
  формой shadcn (FieldGroup/Field, ToggleGroup Доставка/Самовывоз,
  RadioGroup оплаты, aria-invalid). Валидация: мин. 700 ₽, телефон,
  адрес. Тосты — sonner. «Заказать в WhatsApp» собирает текст заказа
  в wa.me. Сумма заказа — в оранжевой плашке шапки.
- **Регистрация и ЛК** `/account` (`lib/auth.tsx`): Tabs
  Регистрация/Вход (имя+телефон / вход по телефону), профиль
  («Здравствуйте, …», сохранение адреса — подставляется в форму заказа),
  история заказов (карточки с составом и итогом), выход, Empty-состояние.
  **Демо-режим на localStorage** — честно подписан в форме; настоящая
  авторизация и приём заказов требуют бэкенда.

## Дополнение (2026-07-22, вечер): промо-карусель

Статичная сетка промо заменена на карусель shadcn Carousel (embla) +
`embla-carousel-autoplay`: горизонтальные слайды (1 на мобиле, 2 на
десктопе), автопрокрутка каждые 5с (loop, пауза при наведении и после
ручного взаимодействия, отключается при `prefers-reduced-motion`),
перелистывание стрелками ‹ › (появляются при ховере) и кликабельными
точками-индикаторами (role=tablist). Тексты чёрных бейджей — с большой
буквы: «Выгода 824 ₽», «0 ₽ за доставку», «Подарки от 1700 ₽».
Проверено кликами: стрелка листает (точка 1→2), клик по точке — прыжок
к слайду, автоплей на свежей загрузке двигает слайды (0→2 за 5.6с).

## Проверено (dev-сервер, реальные клики)

- Типы: `tsc --noEmit` чисто. Консоль браузера чиста после фикса
  `nativeButton={false}` на кнопках-ссылках Base UI (9 мест).
- Главная: 66 карточек, 66 фото загружены (битых 0), h-скролла нет.
- Сквозной флоу: карточка в каталоге → добавление («В корзину» → степпер,
  сумма в шапке 2 010 ₽) → Sheet → форма (имя/телефон/адрес) →
  «Оформить заказ» → тост «Заказ принят», корзина очищена →
  регистрация в ЛК → «Здравствуйте, Алик!», телефон, история с заказом.
- Карточка товара: переход по клику из каталога, фото/цена/степпер/
  похожие, «На главную» возвращает к каталогу (#menu).
- Мобильный вид 393px: шапка (лого-знак, корзина-сумма, кабинет),
  сетка 2 колонки, скриншоты сняты.

## Известные особенности

- Прямой заход на /product/… из превью-пейна откатывался на «/» —
  артефакт навигации превью-инструмента; реальные переходы (клики,
  Link) работают, title страниц корректный.
- GSAP-анимации HTML-версии в приложение не переносились (транзишены
  shadcn); при желании — `gsap-react` отдельным шагом.
- Составы/граммовки большинства позиций в VK не опубликованы — поля
  готовы в `lib/catalog.ts` (`desc`), заполняются по мере получения
  техкарты.

## На решение пользователя

1. Бэкенд заказов и настоящая авторизация (SMS-код), приём заказов
   (Telegram-бот / CRM / iiko) — следующий этап.
2. Продакшен-домен и деплой (`npm run build` готов).
3. Судьба HTML-версии `04-build/sushi-panda/` — оставить лендингом или
   вывести из эксплуатации.
